# NPC alt sağlayıcı birleştirmesi

4599 Python testi ve yeni tam yerel GUI1037 kontrol/11 form/18 sekme geçti. Kayıt ROUTE_NPC_SOURCE_VALIDATION.json.

Gerçek NPC düğmesi NpcSourceFrame üzerinden alt NpcSourceInput kabul eder: üç ayrı hedef getter gözlemi, açık actor lookup dönüşü, signed inline/pointer isim gözlemleri ve geç User Trade Unicode gözlemi. Ready/source kipleri invocation içinde karıştırılamaz; source kipi child boşluklarını hazır değerlerle atlatamaz. Tek istisna ulaşılan kendi UI dialog sonucudur; sağlayıcı dialog değerini atlayamaz.

RouteNpcNameFrame yalnız ulaşılan scalar/nested guard değerlerini ve True normal dönüşleri cache'ler. Eksik kopya aralığı değiştirilebilir; tam kopya normal dönüş beklerken değişmez. Tam512 bayt içinde NUL olmayan source aralığı unresolved kalır. Yanlış adres/uzunluk cache'i bozmaz.

Gerçek düğme testi hazır isim vermeden root/guard/copy verilerinden DC Sundries satırı oluşturdu. İsim copy dönüşü beklerken üçüncü hedef henüz tüketilmedi; gizli formda timer tamamlandı. Lower Royal National verisi kendi dialog2 sonucuyla satıra bağlandı. Önceki gerçek Entry/OK, FIFO, silinen satır ve profil/modal kontrolleri de geçti.

2471 instruction kaydı yeniden doğrulandı. Veriler sentetiktir. Otomatik oyun veri edinimi, dynamic actor lookup ve geç User Trade Unicode üreticisi açık kalır. Kendi timer/FIFO ve lifecycle native timing/SEH/cleanup/callback-return eşliği değildir; güncel oyun profili/erişim ve canlı uyumluluk kanıtlanmadı.
