# NPC rota veri devamlılığı

4565 Python testi geçti;12 yeni test. Kayıt ROUTE_NPC_CLICK_VALIDATION.json.

route_npc_click.py yalnız açık yakalamalarla çalışan API'dir. Üç bağımsız seçili hedef, lookup nesnesi, son std::string isim byte'ları, buff dialog değeri ve ayrı User Trade Unicode dönüşümü ayrı normal dönüş gözlemleriyle alınır. Ulaşılan değerler/True dönüşler tutulur; daha sonra sunulan değişiklikler önceki adımları değiştirmez. Eksik gözlem başarı veya sıfır üretmez.

İsim önceliği Royal National, otion, DC, undries, rmor, eapon, Inn/Kronil şeklindedir. Üçüncü unsigned hedef<=3000 ise User Trade; bu üçüncü0 değeri de olabilir. Dialog yalnız tam0..4 değerlerini kabul eder. User Trade satırı Add/başlık sonrasında Unicode dönüşümünü bekler. Silinen satır, sink hatası ve cancellation tamamlanan yazı önekini korur ve başka satıra yönelmez.

İki kaynak sürümünde callback/yardımcılar ve güncel Unicode equality sarmalayıcıları2222 instruction kaydıyla doğrulandı. Son byte isim/Unicode metin açık gözlemdir; gerçek producer, encoding, native cleanup/SEH ve callback normal dönüşü modellenmedi. complete yalnız bu veri katmanının sonucudur.
