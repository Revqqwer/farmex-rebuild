# Merchant arama metni ve ANSI isim dönüşümü

`merchant_text_normalization.py` kendi Windows ortamındaki iki ayrı normal yolu sunar. `WindowsMerchantText(explicit_code_page).query(text)`, UTF16 uzunluğu boyunca `CharUpperBuffW`, ardından açık kod sayfasıyla `WideCharToMultiByte(flags0)` kullanır. `ansi_name(original_bytes)`, özgün ANSI byte dizisinin tamamında `CharUpperBuffA` kullanır; bu API'nin yorumu sistem ACP'sine bağlıdır. İsim için ekranda görünen Unicode metin yeniden encode edilerek kaynak byte'ları tahmin edilmez.

Pinned RTL Unicode `AnsiUpperCase` ve ANSI `AnsiUpperCase` farklı exportlardır. Kaynak query dönüşümü kod sayfası0 geçirir; pinned RTL bunu `DefaultSystemCodePage` alanından çözer. Bu API açık bir nonzero query kod sayfası ister; source runtime globalini okuduğunu iddia etmez. Kendi x86 standart RTL fixture'ında bu alan1254, ACP1254 ve thread/user LCID1055 ölçüldü. Başka yüklü runtime, OS veya locale için eşlik kanıtı değildir.

Windows büyük harf işlemleri sayılı buffer uzunluğunu kullanır ve aradaki NUL sonrasını da işler; kaynak CString araması bundan sonra ilk NUL'da sonlanabilir. `CharUpperBuff` Türkçe locale'de de `i` karakterini `I` yapar. Bu davranış Microsoft'un [CharUpperBuffW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-charupperbuffw) ve [CharUpperBuffA](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-charupperbuffa) sözleşmeleriyle uyumludur. Kendi native ölçümümüzde `ı` değişmedi, `ß` genişlemedi. Python upper/casefold yerine ayrı API yolları kullanılmasının nedeni budur.

Sonlu native referans:385 vaka,93 Unicode query ve292 ANSI isim örneği;0 fark, tüm normal çağrılarda stack dengeli. ANSI kümesi bütün256 tek byte değerini, birleşik0..255 dizisini, random dizileri ve NUL içeren örnekleri kapsar. Unicode kümesi Türkçe, ASCII, BMP dışı karakterler, tek surrogate, combining işaretler ve uzunluk sınırı örnekleri içerir. Bu, bütün string/locale/kod sayfası uzayının sertifikası değildir. Ham girdiler ve x86/own64 sonuçları `work/merchant_upper_native_inputs.json` ve `work/merchant_upper_native_trace.jsonl` dosyalarında saklanır.

İki Richard sürümünde query Unicode uppercase helper'ı, özgün ANSI isim uppercase helper'ı ve CP0 dönüşüm zinciri; pinned standart RTL gövdeleri ve native importlarıyla birlikte546 talimat kaydıyla doğrulandı. Yeni başarılı REA analizi yoktur; mevcut Ghidra ihracatı/PE baytları ve kendi native deneyleri ayrı kanıtlardır. Orijinal bot helper'ı, game runtime veya diğer süreç belleği çalıştırılmadı/okunmadı.

API sonuçları seçilen query kod sayfasını, host ACP/LCID'lerini, işlenen birim sayısını ve own conversion default-character gözlemini taşır. Bu metadata managed AnsiString header'ının tam modeli değildir. Beklenmeyen API count sonucu açık kapsam eksiğidir; kaynak native çağrının dönüş sayısını göz ardı edebilir. Heap aliasing, SEH, tahsis hataları ve source globalinin canlı değeri hâlâ açık.

4214-test API aşamasında panelde otomatik query dönüşümü etkin değildi. Sonraki MERCHANT_TEXT_BINDING.md aşaması kendi ölçülmüş ACP politikasıyla gerçek paneli bağladı; özgün ANSI isim byte'ları metadata zincirinden taşınıyor. Açık capture önceliği ve eksik ANSI isim kapısı korunur.
