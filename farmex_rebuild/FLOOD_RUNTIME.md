# Çalışan yerel Flood zaman döngüsü

Gerçek `btnAutoFlood` artık bağımsız `OwnedFloodSession` ve kendi Tk zamanlayıcısına bağlıdır. Bu **yerel kuyruk önizlemesidir**: hiçbir socket, oyun handle'ı, native sender, memory write veya server ACK yoktur. Toolbar, oyuna gönderimin bağlı olmadığını gösterir.100ms Tk interval bizim yerel scheduler politikamızdır; orijinal callback'in thread/interval eşliği kanıtı değildir.

Toggle kaynak şekli: her basışta timestamp/index0; kendi mevcut Text'i START literal'ına eşitse active1/STOP caption, aksi halde active0/START caption. Liste boşken de başlar; listeyi yeniden derlemez veya kuyruğu temizlemez. Caption/session/queue render ve profil bağlamasında korunur. Profil liste derlemesi saat/index'e reset eklemez. `btnChatSelected` henüz bağlı değildir.

Bir advance en fazla bir satır işler. Active0 veya count0 saat okumaz. İlk DWORD GetTickCount zero-extend edilir, saklanan QWORD timestamp çıkarılıp signed64 olarak signedDWORD satır gecikmesiyle karşılaştırılır. DWORD rollover'da modulo32 elapsed uydurulmaz. Due değilse yalnız ilk clock vardır. Due ise kendi stabil satır snapshot'ı kullanılır; kaynakta olmadığı için index>=count otomatik clamp/modulo yapılmaz, açık unresolved sonucu döner.

Kanal kendi byte dizisiyle altı literal'a eşlenir: All Chat/Party/Clan/Shout/Merchant/Noah Knight →mode0/2/3/1/4/34 →wire1/3/6/5/14/34. Tanınmayan kanal serializer/kuyruğu atlar; cycle'ın ayrı post clock ve index ilerlemesi yine gerçekleşir. ANSI/Unicode eşitlik helper'larının native algoritma sertifikası verilmez; kendi normal ASCII literal politikamız ve kaynak branch şekli uygulanır.

Paket `10 + wireBYTE + LE16length + CString-prefix` olur. Kaynak assign `004038e4`, `std::char_traits<char>::length` importunu çağırır; kendi byte girdimizde ilk NUL sonrası prefix kullanılır. Orijinal managed/heap/alias akışı yürütülmez. Copy512/toplam516 bayta kadar önceki bounded kaynak kapsamı korunur; canlı counter'a alias yapan daha uzun kopya çözülmüş sayılmaz ve queue eklenmez.

Kuyruk `action_queue.enqueue` ile yalnız kendi immutable payload'ımızı kopyalar. Preview admission gate1, gerçek oyun bağlantısı diye sunulmaz. Raw API gate0'da enqueue clock'u atlar ama cycle post clock/index güncellenir. Gate nonzero ise ilk cycle tick, enqueue tick ve post-helper tick ayrı okunur. Post tick zaman damgasına yazılır; index low32+1 ve yalnız index==count durumunda0 yapılır. Queue commit sonrası post clock eksikse aynı pending frame devam eder, kayıt tekrarlanmaz. Pending snapshot değişirse açık incomplete; toggle pending'i sıfırlar ama commit edilmiş queue kayıtlarını korur.

Incomplete veya stale derleme worker'a verilmez. Bu own stable-snapshot güvenilirlik sözleşmesidir; native concurrent UI/heap/vector davranışı kanıtı değildir. Yerel kayıtlar henüz bir drainer/sender'a aktarılmaz ve stop'ta silinmez. ListHelp'te kayıt sayısı görünür. Timestamp/index/native callback/gerçek gönderim ve canlı uyumluluk tam sertifikası hâlâ yoktur.

12 yeni model testi: caption resetleri/boş start, tek satır/üç saat, wait/equality, signed64 rollover, negative delay,gate0,unknown channel,CStringNUL,512/513 kapsamı,post-clock prefix idempotansı,pending stale/index scope ve stop queue retention. Gerçek gizli widget testi toggle/caption/profile/queue/empty/stop'u kapsar. Ek güncel testte gerçek100ms Tk callback'i150ms event-loop koşusunda yürütülür. Bu test-only ekleme tam UI koşusu başladıktan sonra yapıldığı için ayrıca targeted log'la kanıtlanır; product runtime aynı kaldı. Tam Python4081 ve tüm UI1037/11/18 kontrolleri doğrulanır. Test sayısı tüm botun tamamlanma yüzdesi değildir.
