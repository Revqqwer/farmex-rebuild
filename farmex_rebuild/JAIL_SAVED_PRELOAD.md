# Kaydetme sonucundan ön yüklemeye açık yerel bağ

`SavedWindowPreload`, tamamlanmış `JailSelectionPlan` içindeki kayıtlı ANSI byte satırlarını ön yükleme modeline bağlar. Tamamlanmamış bir producer, türsüz plan veya açık `stable_saved_rows=True` sözleşmesi olmadan başlamaz. Bu sözleşme yalnız kendi sabit fixture'ımız içindir; native oyunda listenin değişmediği iddiası değildir.

Çağıran `vector_begin` ve açık Windows codepage sağlar. Model, bitişi kendi byte satırı sayısından `begin+4*count` olarak DWORD taşmasıyla hesaplar. Hiçbir kaynak okuması veya normal dönüş uydurulmaz. Ön yükleme frame'i hangi raw gözleme ulaşırsa yalnız o değer alınır. İlk/count subtraction/element begin sonuçları ilan edilen fixture begin'iyle, end sonucu ilan edilen fixture end'iyle eşleşmelidir. Çelişki o okumaya ulaşıldığında reddedilir. Bu sabit sözleşme olmadan ham `JailPreloadFrame` taze ve farklı pointer gözlemlerini ayrı işlemeye devam eder.

Source caption normal dönüşü tamamlanınca Unicode pointer intent'i aynen korunur. Buna eşlik eden `(sıra,item,pointer,kendi Unicode metnimiz)` sidecar kaydı, kayıtlı byte satırının **yerel Windows codepage** dönüşümünden üretilir. Pointer dereference edilmez; native string layout veya kaynak RTL dönüşümü doğrulanmış sayılmaz. Caption dönüşü eksikse sidecar üretilmez. Sonraki cleanup/bounds hatası daha önce kabul edilmiş caption/Checked intent'lerini geri almaz. Aynı tamamlanmış frame ikinci kez ekleme yapmaz.

8 test gerçek `JailSelectionFrame` producer'ını ilerletip sonucunu preload'a verir: save→caption/Checked, açık sözleşme/tamamlanma şartı, eksik okumanın doldurulmaması, dört farklı taze bounds çelişkisi, caption/cleanup ayrımı, geç hata sonrası önek ve UTF8/boş kayıt durumu. Statik bağda producer context5690f8+c0 vektörü begin+10=5691c8 ve end+14=5691cc olarak preloader global okumalarıyla eşleşir. İki sabit Richard görüntüsünde140+218 instruction gövdeleri toplam716 kayıt ve iki mevcut REA çıktısıyla tekrar doğrulandı.

API kendi yerel fixture denemesidir; mevcut UI save denemesi henüz bu yeni preload köprüsünü otomatik çalıştırmaz. Gerçek vector lifetime, allocation/object/vtable/SEH/RTL etkileri, window lookup ve oyun uyumluluğu açık kalır. İlgili süreç kontrolünde normal araç bağlamının name/PID listesi0 eşleşme döndürdü; bu bütün masaüstü oturumlarını gördüğümüzü kanıtlamaz. UAC veya bellek erişimi denenmedi. Kanıt: `outputs/FarmexBot_koruma_kayit_on_yukleme_bagi_kaniti.json`.
