# Merchant PM/GİT — kaynak tıklama yolu

`merchant_cell_actions.py`, `004b9784` gövdesinin normal değerler üzerindeki etkisiz planıdır. Başlangıç seçili-index DWORD'u signed negatifse ekran/caption/koordinat gözlemi istemeden çıkar. Pozitif değer, kaynak virtual+0x130 normal dönüşünün ayrı gözlemidir; row count veya vtable nesne kimliği uydurulmaz.

Kaynak `GetCursorPos` BOOL değerini kullanmaz. Form.GetLeft çağrısı ve liste Left alanı okunduktan sonra POINT.x okunur. Toplama/çıkarma DWORD taşmasıyla yapılır, karşılaştırmalar signed'dır. `relative_x = cursor_x - (form_left + list_left)` için735..775 PM,780..820 GİT aralıkları iki uç dahil kullanılır. Bu yordam POINT.y kullanmaz. Başka piksel/DPI/yerleşimlerle eşlik kanıtlanmadı; gerçek Tk sütun numarası bu kaynak aralığının yerine geçirilmedi.

PM yolu seçili satır caption Unicode gözlemini, ayrı CP0 ANSI dönüşümünü, `004ca220(context561ef8,target)` normal dönüşünü ve iki managed cleanup'ı sırayla ister. Görünür caption encode edilerek eksik ANSI gözlemi tamamlanmaz. Ayrı alt helper PM isteği `private_chat_request.py` dosyasındadır. Tek seferlik API opaque receipt alabilir; yeni `MerchantCellFrame`, PM ve motion alt modellerini ayrı parent receipt'leriyle birleştirir. Kapsam MERCHANT_CELL_CHILDREN.md dosyasındadır. Parent helper normal dönüşü, paketin teslim edildiği anlamına gelmez.

GİT, context+0 ve+0x0f BYTE alanlarını sıfırlar; bunlar daha sonraki hata/eksik gözlemde geri alınmaz. Sonra form alanları+0xb64/+0xb68/+0xb6c için1/0/1 etkinlik isteği yapar. Pinned TButton/TControl/TWinControl VMT+0x94 alanları TControl.SetEnabled exportuna eşleşir; gerçek yüklü form nesneleri/override'ları doğrulanmadı. Ardından subitem5/X ve6/Y Unicode metinleri ayrı StrToFloat çağrılarına gider; kaynak FSTP32 sonrası bitler açık girdidir. Python float/locale/yuvarlama veya finite filtresi eklenmedi. Hareket yordamına fiziksel PUSH sırası Y bitleri, sonra X bitleridir. Hareket normal dönüşü ayrıca gereklidir.

14 ilk test signed seçim, iki inclusive aralık/gap, DWORD wrap, başarısız cursor BOOL ile açık x girdisi, PM dönüşüm/cleanup ayrımı, GİT önceki bayrak yazımları/UI sırası, hata öneki ve ham float bitlerini kontrol eder. Tek seferlik immutable gözlem API'si ayrıca kendi prefix-caching frame'iyle tüketilir; ikisi de native event veya Windows cursor okuyucusu değildir.

Kaynak/VCL ve PM alt yordamı ortak kanıtı `FarmexBot_merchant_hucre_PM_kaniti.json`: iki Richard sürümünde930 talimat, pinned VCL'de51 talimat ve üç VMT slot kimliği. Sonraki child bileşimi `FarmexBot_merchant_hucre_alt_akislari_kaniti.json` ve MERCHANT_CELL_CHILDREN.md içinde izlenir. Byte kapsamı tam davranış/SEH/heap/codec sertifikası değildir. Yeni başarılı REA analizi yoktur; mevcut Ghidra/PE kanıtı kullanıldı. Gerçek cell UI, kaynak form/DPI/globals ve native child/canlı oyun etkileri açık kalır.
